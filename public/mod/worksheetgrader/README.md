# Moodle activity: Phiếu học tập & chấm điểm nhóm

Phiên bản 11.3.0-beta4 dành cho Moodle 5.1.

## Chức năng

- Buổi/lượt hoạt động và nhóm động riêng theo từng buổi.
- Mở khóa để đổi nhóm khi buổi đang diễn ra, rồi khóa lại để học sinh tiếp tục.
- Import DOCX/PDF qua Python Engine hoặc tự thiết kế phiếu trực quan.
- Editor có bảng, thêm/xóa hàng cột, checkbox, ô ngắn, ô dài, thông tin Moodle và vùng nộp ảnh.
- Một tài khoản đại diện làm, autosave và nộp cho toàn bộ nhóm.
- Ảnh sơ đồ tư duy/bài vẽ lưu bằng Moodle File API và hiển thị inline khi chấm.
- Tất cả thành viên xem chung bài làm, điểm và phản hồi.
- Giáo viên vừa xem phiếu/ảnh đã nộp vừa chấm trong giao diện chia đôi.
- Điểm nhóm, điều chỉnh cá nhân, Gradebook, completion và báo cáo.

## Quy trình

Tạo buổi → Thiết kế/import nội dung → Chia nhóm → Mở buổi → Học sinh làm/nộp → Chấm điểm → Báo cáo.

Khi cần đổi nhóm giữa buổi:

Mở khóa chia nhóm → chỉnh nhóm/đại diện → lưu → khóa lại.

Không uninstall bản cũ trước khi nâng cấp.
